🚀 Quick Start (5 minutos)

Los pasos mínimos para ejecutar el API:

# 1. Preparar datos cd ~/Documentos/IA/geocoding-medellin mkdir -p data/gpkg unzip gpkg_*.zip -d data/gpkg/ # 2. Iniciar servicios sudo docker-compose up -d # 3. Esperar (5 min aprox) sudo docker-compose logs -f api # 4. Probar curl http://localhost:8000/api/v1/geocode \ -H "Content-Type: application/json" \ -d '{"direccion":"Calle 39 # 35-35"}' # 5. Interfaz web open test.html

🔌 Endpoints de API

Todos los endpoints disponibles:

Método Endpoint Descripción Precisión
GET /health Estado del servidor -
GET /stats Estadísticas de datos -
POST /api/v1/normalize Normaliza dirección -
POST /api/v1/geocode Geocodifica dirección (3 niveles) ±2m a ±100m
POST /api/v1/geocode/batch Geocodifica múltiples ±2m a ±100m

Después de iniciar, ejecuta estos checks:
