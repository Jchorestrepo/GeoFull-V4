# Brag Plan: GeoFull V4 — Importación de Guías & Sectorización

## What is this app?
GeoFull V4's automated bulk Excel/CSV guide import feature that processes thousands of shipping orders, normalizes street addresses, geocodes them across 7 PostGIS precision levels, and assigns spatial sector zones instantly.

## The angle
A sleek Apple dark minimalist product demonstration showing the step-by-step flow of importing a shipping batch into GeoFull V4 and receiving an instant spatial sectorization breakdown.

## Hook (first 2-3 seconds)
A glowing glassmorphic dropzone: "IMPORTACIÓN MASIVA DE GUÍAS EXCEL / CSV" with animated drop action.

## Key moments (the middle)
- **Step 1 — File Drop & SaaS Template Match**: Excel file loaded, auto-mapped to active SaaS template.
- **Step 2 — Real-time Pipeline Execution**: Live progress bar (0% → 100%) showing Sanitizer V3 → PostGIS 7-Level Geocoder → ST_Contains Sectorizer.
- **Step 3 — Post-Import Summary Report**: Interactive stats showing Geocodificados OK (Emerald Green), Fuera de Zona (Amber), Requiere Revisión (Red).

## Outro / punchline
"GeoFull V4. Importación & Sectorización en Segundos." Logo & CTA.

## User flow worth showing
Drag & Drop Excel File → Automated Pipeline (Sanitizer → PostGIS 7-Level → Sectorizer) → Post-Import Summary Report & Zone Map.
